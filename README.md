# 介護記録システム（kaigo-ondoban）

老健施設の職員向け介護記録Webアプリケーション。Google Apps Script と Google スプレッドシート連携で、音声入力・タップ操作による簡単な記録入力を実現します。

---

## 📋 概要

### 対象施設
- 老健施設（老人保健施設）
- AI導入が難しい環境での現実的なツール化

### 主な特徴
- **GAS連携** — Google Apps Script 経由でスプレッドシートに自動記録
- **シンプルUI** — タップ操作で摂取量・排泄記録を記録
- **ゼロコスト** — Google スプレッドシート + GAS で実装
- **施設カスタマイズ対応** — 利用者ごとに独立したシート作成可能

---

## 🎯 機能

### 食事・水分記録
- 利用者名簿から選択
- 主食・副食・水分を記録
- タップサイクルで摂取量を段階的に選択（全量 → 8割 → 6割 → 4割 → 2割 → なし）
- 特記事項入力

### 排泄記録
- 排泄時刻・回数の記録
- 浣腸・下剤の使用記録

### 看護記録
- バイタル（体温・血圧等）
- 観察所見
- 特記事項

## 🚀 セットアップ手順

### 1. Google Apps Script プロジェクトの作成

```
1. https://script.google.com にアクセス
2. 「新しいプロジェクト」をクリック
3. kaigo_gas.js の内容をコピーして貼り付け
4. 自分の Google Drive フォルダ ID を取得（下記参照）
```

### 2. フォルダ ID の設定

Google Drive で記録を保存するフォルダを開き、URL から ID を抽出：

```
例: https://drive.google.com/drive/folders/1ABC123XYZ
           ↓ この部分がフォルダ ID
FOLDER_ID の値として kaigo_gas.js に貼り付け
```

### 3. GAS デプロイ

```
1. kaigo_gas.js 編集画面で「デプロイ」をクリック
2. 「新しいデプロイ」→ 種類「ウェブアプリ」
3. 実行ユーザー＆アクセス権限を設定
   - 実行ユーザー: 自分
   - アクセス: 全員（Googleアカウント不要）
4. 発行されたウェブアプリのURLをコピー
```

### 4. Webアプリ設定

`kaigo_kiroku_v15.html` の以下の行を修正：

```javascript
const GAS_URL = "ここにGAS_URLを貼り付ける";
```

発行されたウェブアプリ URL を上記に貼り付けます。

### 5. 利用開始

- `kaigo_kiroku_v15.html` をブラウザで開く
- 利用者を選択して記録開始

## 📊 スプレッドシート構成

GAS が自動作成するシート：

| シート名 | 用途 |
|---|---|
| 食事・水分 | 食事・水分摂取量の記録 |
| 排泄記録 | 排泄時刻・尿便の記録 |
| 看護記録 | バイタル・観察所見 |

各シートは以下の列で構成：
- 記録日時 / 利用者名 / 部屋番号 / 具体的な記録項目 / 特記事項

## 📝 注意事項

- **初期設定が必須** — GAS URL と フォルダ ID の設定なしでは動作しません
- **Google アカウント** — 利用者は Google アカウント不要ですが、管理者用の G Suite or 個人 Google アカウントが必要
- **データ保護** — 個人情報を含むため、Google Drive のアクセス権限を適切に管理してください

## 🔧 トラブルシューティング

### GAS 接続エラーが出る
- GAS_URL が正しく設定されているか確認
- GAS のデプロイ時に「アクセス: 全員」が選択されているか確認

### 記録が保存されない
- Google Drive のフォルダ権限を確認
- FOLDER_ID が正しく設定されているか確認
- ブラウザのコンソール（F12）でエラーメッセージを確認

### スプレッドシートの列が足りない
- GAS の `SHEET_HEADERS` 定義を確認
- 必要に応じてカスタマイズ
